        Settings

        Connect the Android app, and choose how it reaches this computer.

        Connect your phone on this Wi-Fi

        Phone access is off. Stop the server and start it with python -m memora --lan --port 8010, with the phone and this computer on the same Wi-Fi.

        In the Android app, open Settings → Laptop connection and enter:

        Address
        Port
        Pairing code

        Only devices with this code can use Memora. If the phone can't connect, allow port through Windows Firewall for private networks (see README).

        Tailscale off

        Optional. Lets the phone reach this computer from another network through your private Tailscale network. Install the official Tailscale app on both devices and sign in to the same account. Tailscale doesn't make Memora available when this computer is off, and Memora still requires the pairing code.

        To turn it on, stop the server and start it with:

        python -m memora --lan --tailscale --port 8010

        Tailscale address
        Port

        Enter this address in the Android app: Settings → Tailscale.

        Windows Firewall: if the phone can't connect through Tailscale, allow inbound TCP on the Memora port from the Tailscale range only, for example New-NetFirewallRule -DisplayName "Memora (Tailscale)" -Direction Inbound -Protocol TCP -LocalPort 8010 -RemoteAddress 100.64.0.0/10 -Action Allow. Don't open the port to other addresses. Use Tailscale's access controls to decide which of your devices may reach this computer.

        Photo analysis checking

        Photos are read and described by a model running in Ollama on this computer, and text in photos is read with Windows' built-in text recognition. Nothing is sent to any online service. The model is chosen with MEMORA_VISION_MODEL (default: the chat model, if it can see images).

        Privacy

        Your files and their text stay on this computer. This page is only served to this computer; phones can use the API only, and only with the pairing code. Memora's web page keeps no analytics.
